Loko Immeuble — Android app skeleton

This folder contains a minimal Android (Java) project scaffold to start development.

Prerequisites
- Android Studio or Android SDK + Gradle
- Java JDK 11 or 17

How to use
1. Open the `android` folder in Android Studio.
2. Copy the generated Android icons into the app module `app/src/main/res/mipmap-*/` folders. You can find the icons here: `dist/branding/icons/android/`.
3. Build and run on a device or emulator.

Notes
- This is a minimal scaffold (SplashActivity, MainActivity, basic layouts). Add features iteratively from here.
